# 1. Project Overview

> **Status:** Implemented prototype; see the root README and Sprint 5 QA report for current behavior and validation evidence.

Harbor Tickets is a web-based IT helpdesk prototype for making routine IT support faster and more consistent. Employees can ask technical support questions through Harbor, create and track tickets, and request human assistance. Agents work assigned tickets, reply in linked conversations, draft solutions, and submit knowledge pairs. Administrators manage users, ticket assignment, knowledge content, and operational metrics.

## Target Users

1. **Employees** requesting IT assistance.
2. **IT support agents** who review and resolve tickets.
3. **Administrators** who manage knowledge-base content, access permissions, and operational metrics.

The initial prototype uses fictional sample users, tickets, and IT procedures.

## Intent of the Prototype

The system is intended to demonstrate:

- Grounded answers from a curated support knowledge base
- Authenticated, role-checked ticket and conversation workflows
- Human escalation and agent ticket operations
- Administrative user, knowledge, and operational views

It is a capstone prototype, **not** a deployment connected to a real organization's identity directory or production IT infrastructure. Chat answers use the local knowledge-answer path; Gemini is used server-side for optional ticket-solution drafts.
