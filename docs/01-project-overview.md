# 1. Project Overview

> **Status:** Draft for team review. Details are provisional.

AI-HAS is a proposed web-based IT helpdesk platform for an organization that wants to make routine IT support faster and more consistent. Employees can ask technical support questions through a conversational interface. The system retrieves relevant information from an IT knowledge base, generates answers grounded in that information, creates or updates support tickets, and escalates unresolved or sensitive requests to a human IT support agent.

## Target Users

1. **Employees** requesting IT assistance.
2. **IT support agents** who review and resolve tickets.
3. **Administrators** who manage knowledge-base content, access permissions, and operational metrics.

The initial prototype uses fictional sample users, tickets, and IT procedures.

## Intent of the Prototype

The system is intended to demonstrate:

- Retrieval-Augmented Generation (RAG)
- Controlled AI function calling
- Webhook-based workflow automation
- Basic operational analytics

It is a capstone prototype, **not** a deployment connected to a real organization's identity directory or production IT infrastructure.
